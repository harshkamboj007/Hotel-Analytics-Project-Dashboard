# 🏨 Hotel Booking Analytics

## 📌 Project Overview

This project analyzes **hotel booking data using SQL Server** to identify patterns in bookings, revenue, ADR, cancellations, customer behavior, lead time, and length of stay.

The project follows a structured data workflow from **Bronze → Silver → Gold → Business Analysis**, with the Gold layer serving as the foundation for business-focused SQL analysis.

The objective is to transform hotel booking data into **meaningful business metrics and insights** that can support analysis of hotel performance, customer behavior, revenue, and cancellations.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze **hotel booking performance**
* Understand **revenue and ADR patterns**
* Analyze **cancellation behavior**
* Identify the relationship between **lead time and cancellations**
* Compare **repeat and non-repeat guest behavior**
* Analyze **market segments and distribution channels**
* Understand **revenue contribution by stay duration**
* Analyze **monthly revenue and cancellation trends**
* Practice advanced **SQL for business analysis**

---

## 🏗️ Data Architecture

The project follows a layered approach:

```text
Raw Data
    ↓
Bronze Layer
    ↓
Silver Layer
    ↓
Gold Layer
    ↓
Business Analysis
    ↓
Business Insights
    ↓
Power BI Dashboard
```

### 🥉 Bronze Layer

The Bronze layer contains the initial ingestion of the source data.

The purpose of this layer is to retain the source data in a structured form before further transformation.

### 🥈 Silver Layer

The Silver layer is used for data cleaning and transformation.

This layer prepares the data for analytical use by applying the required transformations and standardization.

### 🥇 Gold Layer

The Gold layer contains the **analytics-ready data** used for business analysis.

The analysis uses fields such as:

* Hotel
* Arrival date
* ADR
* Total stay nights
* Total guests
* Booking status
* Lead time
* Market segment
* Distribution channel
* Repeated guest status
* Room change status

### 📊 Business Analysis Layer

The Business Analysis layer uses SQL to answer business-oriented questions using the Gold-layer data.

## 📊 Power BI Dashboard
An interactive **2-page Power BI dashboard** was developed to analyze hotel booking performance, revenue, customer behavior, and cancellation patterns.

## 📈 Key Analysis Examples

### Revenue Share by Market Segment

Revenue is calculated using:

```sql
ADR × Total Stay Nights
```

The analysis then calculates each market segment's percentage contribution to total revenue using a window function.

### Month-over-Month Revenue Analysis

Monthly revenue is calculated and compared with the previous month using:

```sql
LAG()
```

This allows the analysis to identify the percentage change in revenue from one month to the next.

### Lead Time vs Cancellation

Bookings are grouped into lead-time buckets and analyzed using:

* Booking volume
* Average ADR
* Cancelled bookings
* Cancellation rate

This provides a structured way to examine the relationship between **booking lead time and cancellation behavior**.
